# MediaPipe interactive segmentation assets

These files are bundled locally so object selection continues to work after the PWA has been cached.

- `magic_touch.tflite`: Google MediaPipe Magic Touch interactive segmenter model from `https://storage.googleapis.com/mediapipe-models/interactive_segmenter/magic_touch/float32/1/magic_touch.tflite`
- `vision_wasm_internal.js` and `vision_wasm_internal.wasm`: copied from `@mediapipe/tasks-vision` 1.0.1
