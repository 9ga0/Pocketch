# 브라우저 배경 제거 기술 결정

## 결정

채집 3단계는 `@mediapipe/tasks-vision` 1.0.1의 Magic Touch 모델을 우선 사용한다. 사용자가 사진에서 남길 물건을 한 번 터치하면 해당 지점을 관심 영역으로 전달해 마스크를 생성한다. 모델 초기화나 추론에 실패할 때만 `@imgly/background-removal` 1.7.0의 `isnet_quint8` 모델로 자동 전환한다. 촬영 원본은 API로 보내지 않으며, 브라우저 메모리에서 배경 제거·알파 여백 자르기·1024px 축소·투명 WebP 변환을 마친 뒤 결과만 IndexedDB에 저장한다.

첫 실행에는 Magic Touch 모델과 MediaPipe WASM, 대체 처리용 IS-Net 모델과 ONNX WASM 다운로드가 필요하다. 촬영 화면이 열릴 때 Magic Touch를 미리 준비하고 브라우저 캐시를 재사용한다. 운영 배포에서는 공급자 CDN 장애와 버전 변동을 피하기 위해 모든 모델과 런타임을 같은 출처의 정적 자산으로 자체 호스팅한다.

## 비교

| 후보 | 객체 사진 적합성 | 브라우저 실행 | 라이선스·배포 판단 |
| --- | --- | --- | --- |
| `@imgly/background-removal` 1.7.0 | 제품·일반 객체용 IS-Net 제공 | ONNX Runtime Web, 모델 캐시 지원 | 라이브러리 AGPL-3.0. 공개·상업 배포 전에 AGPL 의무를 준수하거나 IMG.LY 상용 라이선스 필요 |
| Transformers.js + MODNet | 인물 중심 | WebGPU/WASM 지원 | 런타임 Apache-2.0이지만 채집 대상 품질이 맞지 않음 |
| Transformers.js + BRIA RMBG | 일반 객체에 적합 | Transformers.js 모델 제공 | 모델이 비상업 용도 제한 및 게이트되어 제품 기본값으로 부적합 |

이번 선택은 기능 검증과 공개 소스 개발에 적합하다. 배포 정책이 정해지기 전에는 라이선스 검토를 완료해야 한다.

## 데이터와 실패 처리

- 네트워크 요청은 모델·WASM 정적 자산에만 발생한다. 촬영 Blob을 `fetch`, FormData, URL 파라미터에 넣지 않는다.
- 모델 다운로드 또는 추론 실패 시 원본을 저장하지 않고 재시도와 취소를 제공한다.
- Magic Touch 처리 실패 시 IS-Net으로 한 번 자동 재시도하며, 완료 결과에서는 같은 원본을 다시 터치해 선택을 수정할 수 있다.
- 취소 세대 번호를 올려 늦게 끝난 비동기 결과를 무시하고 생성한 object URL과 ImageBitmap을 해제한다.
- 완전 투명 결과, 디코딩 실패, WebP 인코딩 실패를 각각 복구 가능한 오류로 표시한다.
- 이름은 공백 제거 후 필수이며 설명은 선택이다. 저장 버튼은 쓰기가 끝날 때까지 잠근다.
- IndexedDB 저장 성공 뒤에만 React 목록과 Phaser 브리지에 같은 항목을 한 번 추가한다. 재시도에는 같은 ID를 사용한다.

## 성능 확인 기준

Chrome 실제 기기에서 개발자 도구의 Network를 열고 촬영 이미지를 한 번 처리한다. 첫 실행의 모델 다운로드 시간과 전체 처리 시간을 기록한 뒤 같은 탭에서 두 번째 사진을 처리해 캐시 재사용 시간을 비교한다. 요청 목록에 촬영 이미지 업로드가 없고, 결과의 긴 변이 1024px 이하이며 MIME 타입이 `image/webp`인지 함께 확인한다.
