# Pocketch

> 내 물건을 촬영하고, 쌓고, 받아내는 현장 참여형 웹게임

Pocketch는 관람객의 실제 소지품을 노트북 카메라로 촬영해 투명 배경의 게임 아이템으로 만들고, 화면에 물리적으로 쌓거나 키보드로 받아내며 즐기는 단일 기기용 부스 웹게임입니다.

## 체험 흐름

1. 노트북 카메라로 물건을 촬영합니다.
2. 사진에서 남길 물건을 터치해 배경을 제거하고 이름과 설명을 등록합니다.
3. 등록된 물건이 화면 위에서 떨어져 다른 물건과 충돌하며 쌓입니다.
4. 닉네임을 입력하고 30초 동안 바구니를 움직여 떨어지는 물건을 받습니다.
5. 점수를 기기 내 랭킹에 기록하고 다시 도전합니다.

## 핵심 기능

- 촬영 전용 모달에서 처리하는 브라우저 카메라 촬영과 결과 미리보기
- 원터치 객체 선택을 이용한 클라이언트 측 배경제거 및 로컬 이미지 저장
- 기울기·흔들기(또는 포인터 드래그)로 움직이는 반응형 물리 기반 아이템 더미
- 물건 이름·설명 확인과 개별 삭제
- 링크 하나로 다른 기기·브라우저에서 조회할 수 있는 채집 세션 공유(옵트인)
- 방향키 또는 `A/D`를 사용하는 30초 캐치 게임
- 닉네임 기반 로컬 상위 10위 랭킹
- 검은 배경 중심의 미니멀한 반응형 인터페이스

## 목표 실행 환경

- 노트북 내장 카메라와 키보드
- 최신 데스크톱 Chrome
- 인터넷 연결이 가능한 현장 환경
- 별도 서버 없이 정적 웹으로 배포 가능한 단일 브라우저 애플리케이션

## 예정 기술 스택

- IndexedDB

## 로컬 실행

Node.js 20.19 이상 또는 22.12 이상에서 실행합니다.

```bash
npm install
npm run dev
```

프로덕션 빌드와 검증 명령은 다음과 같습니다.

```bash
npm run typecheck
npm test
npm run build
```

프로덕션 빌드에는 앱과 객체 선택·배경제거 모델을 선캐시하는 Service Worker가 포함됩니다. 행사 장비에서 온라인으로 한 번 열어 상단의 `오프라인 준비 완료`를 확인하면 이후 네트워크 없이 사용할 수 있습니다. 자세한 절차는 [오프라인 배포 안내](docs/OFFLINE_DEPLOYMENT.md)를 참고하세요.

## 채집 세션 공유 설정 (선택 기능)

채집 화면의 `공유 링크 만들기`는 무료 Firebase(Firestore + 익명 인증) 프로젝트가 있어야 동작합니다. 설정하지 않아도 나머지 기능은 오프라인 그대로 동작하며 공유 버튼만 비활성화됩니다.

1. [Firebase 콘솔](https://console.firebase.google.com)에서 프로젝트를 만듭니다(Spark 무료 플랜, 카드 등록 불필요).
2. `Firestore Database`를 만들고, `Authentication` > `Sign-in method`에서 `익명(Anonymous)` 로그인을 켭니다.
3. 이 저장소의 `firestore.rules`를 Firebase 콘솔 또는 `firebase deploy --only firestore:rules`로 배포합니다.
4. 프로젝트 설정 > 일반 > 내 앱(웹)에서 발급된 값을 `.env.example`을 참고해 `.env.local`에 채웁니다(`VITE_FIREBASE_API_KEY` 등).
